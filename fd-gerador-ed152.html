1. Publicar no GitHub Pages

Faça esta etapa antes de copiar para o e-mail. O índice do e-mail aponta para esta página.

Baixar gera o arquivo já nomeado pelo número da edição, pronto para arrastar em Add file → Upload files. Copiar HTML completo serve para o caminho sem download, em Add file → Create new file, dando o nome do arquivo e colando o conteúdo. Os dois entregam o mesmo HTML, com <head> e folha de estilo — que é o que a página precisa e o e-mail não aceita.

Não use "Abrir em nova aba" e salvar pelo navegador. Isso grava o DOM renderizado, não o HTML gerado.

2. Versão e-mail (Proton Mail)

Use este botão em vez de abrir em nova aba e selecionar tudo. Ele escreve o HTML exato na área de transferência, com as âncoras do índice intactas. Selecionar a página renderizada faz o navegador reserializar a seleção, e é aí que a navegação interna se perde antes mesmo de chegar ao Proton.

Teste obrigatório antes de disparar. Cole no compositor, envie para você mesmo e clique numa linha do índice. Se não saltar, o sanitizador do compositor descartou as âncoras e não adianta insistir no formato.
